# v0.1 Publication Staging Notes

This first public staging release is intentionally narrow.

## Included

- Application-focused Decision-PGA article draft with healthcare as one
  evaluation lens.
- Preserved draft archive for earlier wording and ideas.
- Explanatory diagnostic-loop diagram.
- Shareable PDF preview generated with browser print layout.
- No-cost publication plan.
- Public GitHub Pages-ready site structure.
- Claim guardrails around patient data, clinical validation, institutional
  endorsement, and medical-device or clinical-decision-support status.

## Not Included Yet

- Public release of the main Decision-PGA prototype code.
- Clinical validation.
- Patient data or private workflow examples.
- Named institutional positioning or endorsement.
- A formal benchmark paper.
- Any claim that Decision-PGA is production-ready.

## Intended Next Step

Use this site for early public review while the main prototype repository is
kept private. After feedback and repo hardening, publish a tagged code release
and update this site to link to it.
